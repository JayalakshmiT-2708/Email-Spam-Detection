# 📧 Email Spam Detection using Machine Learning

## 📌 Overview

This project is a Machine Learning-based Email Spam Detection system that classifies incoming messages as **Spam** or **Ham (Not Spam)**. It uses Natural Language Processing (NLP) techniques to preprocess text data and a trained machine learning model to make predictions.

The application provides a simple and interactive interface for users to enter an email or message and instantly check whether it is spam.

---

## 🚀 Features

* Email/Text classification into Spam or Ham
* Text preprocessing and cleaning
* Machine Learning-based prediction
* Simple and user-friendly interface
* Real-time prediction for custom input messages

## ⚙️ Working Flow

1. Load the Spam/Ham dataset.
2. Preprocess the text data.
3. Convert text into numerical features.
4. Train the Machine Learning model.
5. Accept user input through the application.
6. Predict whether the message is Spam or Ham.

---

## 📊 Dataset

The project uses a labeled Spam/Ham email dataset containing thousands of text messages categorized as:

* **Spam**
* **Ham (Legitimate messages)**

The dataset is included in this repository as:

`spam_ham_dataset.csv`
